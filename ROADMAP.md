# Roadmap

## Initial implementation
Milestones 1–8: application, bounded GitHub ingestion, 24-rule deterministic engine, results/evidence, conditional improvements, two modes, atomic quotas/cache, deliberate sharing.

Milestone 9: mocked unit/runtime/browser checks, accessibility and representative fixture profiles. Live ecosystem calibration and external staging smoke tests remain release gates.

Milestone 10: Cloudflare configurations, staging/production secrets, DNS/HTTPS and rollback instructions. Actual deployments require the requested authorization and configured account.

## After calibration
Improve ecosystem recognition without inflating rule count; inspect configuration semantics conservatively; expand reviewed humor templates; evaluate true Open Graph PNG previews (current OG metadata is text only); support alternative CI evidence beyond path recognition; revisit beta capacity from measured usage.

## Non-goals
AI inference, accounts, private repos, OAuth, GitHub write access, automated PRs, billing, subscriptions, leaderboards, historical comparisons, desktop integration, or unnecessary infrastructure.
